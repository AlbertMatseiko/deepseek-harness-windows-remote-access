# Security

## Threat model

`/latest` is an endpoint that returns the current DSH launch token after Basic Auth. In practice it is an entry point to an agent that can read/write files and run commands on the PC. Therefore:

- tailnet membership alone is not enough: the Basic Auth password is also required;
- access to `/latest` is equivalent to access to DSH;
- a URL containing `?token=...` is itself a secret while the DSH process is alive.

## Where secrets live

| File | Contents | Protection |
|---|---|---|
| `%USERPROFILE%\.dsh\remote-config.ps1` | PC tailnet DNS name | outside the repository; do not publish |
| `%USERPROFILE%\.dsh\latest-auth.json` | username + salt + SHA-256 password hash | ACL for the current user |
| `%USERPROFILE%\.dsh\latest-url.txt` | live DSH launch token | ACL for the current user |
| `%USERPROFILE%\.dsh\.credentials.yaml` | DeepSeek API key | written by DSH; do not read or print |
| Hiddify subscription URL | node access | do not publish |
| Tailscale auth key | one-off LxBox login | do not publish; not needed after use |

## Network protection

- DSH listens only on `127.0.0.1:3080`.
- Tailscale Serve publishes `/` and `/latest` only inside the tailnet.
- **Do not enable `tailscale funnel`**; it exposes the service to the internet.
- Tailscale ACLs should allow only your devices.
- The phone and laptop are trusted devices; if the phone is lost, revoke the LxBox node in the admin console.

## Basic Auth password

The password is stored only as a salted SHA-256 hash; it is never saved in plaintext.

### Changing the password

1. Set a new password:

```powershell
pwsh -NoProfile -File .\scripts\setup-auth.ps1
```

2. Restart the redirect server/DSH — it reads the auth file at startup:

```powershell
# stop the current start-dsh.ps1 window, then:
pwsh -NoProfile -File .\scripts\start-dsh.ps1
```

If you use the scheduled task:

```powershell
Stop-ScheduledTask -TaskName "DSH Web latest"
```

```powershell
Start-ScheduledTask -TaskName "DSH Web latest"
```

3. Clear the Basic Auth cache in the phone browser for `<pc>.<tailnet>.ts.net`, or open `/latest?nocache=...` in a private tab.

The old password stops working after the redirect server restarts. The DSH token does not change.

### If you forget the password

Run `setup-auth.ps1` again and restart DSH. The old hash is overwritten.

## DSH token

- The token is generated by the `dsh web` process and changes on every restart.
- `latest-url.txt` stores the current token; `start-dsh.ps1` updates it on every launch.
- If you start `dsh web` manually, the file becomes stale and `/latest` serves an invalid token.
- After the redirect, the token may end up in browser history. For strict setups, open `/latest` in a private tab.
- If the token leaks, restart DSH; the old token becomes invalid.

## Limitations

- Basic Auth is sent only over HTTPS (Tailscale), but it does not replace phone lock.
- `/latest` has no rate limiting; use a strong password and an ACL.
- LxBox is a third-party GPL client; trust in it is separate from this repository.
- DSH is a developer preview; do not treat it as the only security boundary for untrusted workloads.
